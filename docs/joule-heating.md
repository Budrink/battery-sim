# Джоулев нагрев и новая калибровка

## Зарядочная поляризация по запасу вещества (23.10.2026)

Текущая ревизия использует `charge_state_input="stored_precursor"` и
`R_local = R0 exp[a(T-T_ref) + b u]`, где `u = m_Bc/(m_A+m_Bc)`.
Это дополнительный зарядный реагент, **не полный SOC** исходной батареи.
Непринятая из-за UI зарядная работа не увеличивает Bc. Расход Bc через R2
уменьшает зарядочную составляющую R; деградация R1 по-прежнему отдельно
ухудшает электрическую проводимость смеси и уменьшает доступную ёмкость.
Параметры старого закона по прошедшему заряду нельзя молча переиспользовать.
Для ненулевого b входной файл обязан явно назвать новый тип состояния.
Старые бинарники и результаты сохраняются, новые расчёты начинаются заново;
контрольные состояния между ревизиями не переносятся. Закон не добавляет
новых переменных, источников тепла или энергетических ограничителей.

## Явный тип входного тока (22.10.2026)

`electrical.current_input = "measured"` — режим по умолчанию: ток задан
измерением. Нарушение UI-баланса является ошибкой, никакого ограничения тепла нет.

`"voltage_limited_setpoint"` — отдельное допущение для неотрицательной уставки
источника, когда фактический ток не записан. При замороженном на подшаге
сопротивлении Кирхгофа `I = min(I_set, max(0,U-E_floor)/R)`.
Это предельная электрическая модель источника, не восстановленный измеренный
ток и не доказательство корректности R(Q). При E_floor=0 граница соответствует
нулевому остатку работы для зарядного химпотенциала; новый порог ЭДС не вводится.

Интегралы I, I² и UI вычисляются аналитически по общим узловым точкам профилей
и пересечениям ветвей, один раз на объект в CUDA. Зарядный химпотенциал,
джоулево тепло и проверка UI используют один фактический ток.
Сопротивление использует запасённый Bc, а не интеграл тока.
Накопленный положительный заряд входит в коммит/повтор/рестарт вместе
с остальным состоянием. При повторной подготовке он не начисляется второй раз.
Минимальный шаг и допуски сохранения энергии не ослабляются.

В охлаждаемом опыте UPV известна уставка 35 А, но нет измеренного лога тока.
Однако описание опыта прямо задаёт constant-current35А до потери непрерывности
при compliance80В. **Измеренное U батареи не является пределом напряжения
источника.** Проба с этим U как compliance — только диагностика ядра с ДРУГИМ
протоколом, не физическая валидация UPV. Отсутствие токового лога не даёт права
считать падение расчётного тока до6–7А нормальным следованием этой уставке.
Для корректной validation текущий R(T,Bc) должен согласоваться с measured UI
при prescribed35А либо его несовместимость должна быть признана отказом модели.
Калибровочный лог этим режимом не заменяется; прежние C/k/контакты/химия фиксированы.

CUDA решает квазистационарную задачу Кирхгофа на электрическом графе ядра,
независимом от тепловых контактов и газовых маршрутов. Затем считает локальное
Джоулево тепло независимо от R1/R2/R3.
Электрическая энергия хранится в отдельном `joule_energy_j`, не списывается из
химического запаса и отдельно входит в глобальный термобаланс. При разбиении
батареи на объёмы тепло распределяется по найденным токам и сопротивлениям,
не равномерно и не пропорционально оставшемуся запасу химического топлива.

## Проводимость смеси и электрическая геометрия

23.10.2026: электрический закон допускает явную таблицу
`temperature_log_response: [[T_K, log(R_T/R_ref)], ...]` (2–8 узлов).
Она заменяет, а не дополняет `temperature_log_slope_per_k`; значение при
`reference_temperature_k` должно быть нулевым. Между узлами — линейная
интерполяция, вне таблицы — постоянные концы, как у других конститутивных
профилей. Это позволяет явно задать ограниченное высокотемпературное
продолжение закона вместо бесконечной экстраполяции холодной экспоненты.
Таблица не зависит от измеренного U, времени или номера опыта; это не
ограничитель мощности. Кирхгоф, фактическое I²R, оплата зарядного запаса и
строгий UI-контроль остаются прежними. Высокотемпературный хвост — явная
гипотеза для проверки, не измеренная характеристика материала.

Для всех конденсированных продуктов R1/R2 используется один коэффициент
`0 < product_conductivity_ratio <= 1`, без отдельных проводимостей каждой реакции:

При ненулевой зарядочной поляризации проводимости фаз суммируются:

`σ_eff = [(m_A+m_Bc)/R_healthy(T,u) + η(m_Bd+m_residue)/R_base(T)] / m_initial`.

Здесь `u=m_Bc/(m_A+m_Bc)`, `R_healthy=R_base*exp(b*u)`. При b=0 это
точно прежний весовой множитель смеси. Продукты не приобретают поляризацию
здорового вещества: исчезающе малый остаток Bc не должен увеличивать
сопротивление всей массы продуктов. Это исправление электрики, без изменения
запасов R1/R2, их скоростей, тепловой проводимости или химического баланса.

Здоровые A и зарядный Bc имеют исходную электрическую проводимость;
реагент деградации Bd и общий остаток S/C — пониженную η. Унесённое газом вещество не
остаётся проводником. Тепловая проводимость задаётся отдельно и не умножается
на η. Значение η=0.2 — стартовая априорная оценка, не измерение.

`resistance_ohm` нормирует сопротивление **целой однородной неповреждённой**
батареи. Температурный множитель исходного удельного сопротивления
`exp[a(T-T_ref)]` сохранён. Поляризация по мере зарядки — тот же эффективный R:
`exp[b m_Bc/(m_A+m_Bc)]`, по умолчанию `b=0`. Это I²R, не списание `U·I` в тепло.
Старое `damage_log_slope` удалено: изменение состава не должно второй раз
увеличивать R через эмпирический D.

`terminal_axis` выбирает x/y/z: две противоположные полные грани считаются
идеальными эквипотенциальными выводами. Это эффективная омическая геометрия,
не реконструкция электродов/токосъёмников pouch-ячейки. Для UPV явно задан z
и отмечен как неизмеренное приближение. Изоляция, TIM, корпус и соседние батареи
не получают электрических связей из тепловой сетки.

Общая геометрия строится на хосте один раз. На каждом подшаге CUDA обновляет G,
решает `Σ_j G_ij (V_i-V_j)=I_i` предобусловленным CG и нормирует решение на
заданный полный ток. Один блок владеет одной батареей, суммирования имеют
фиксированный порядок. Начальное приближение берётся из предыдущего **принятого**
шага; потенциалы, диагностика и тепло новой попытки коммитятся вместе с остальными
состояниями. Токи, итерации и балансы не синхронизируются с CPU внутри CG.
При нулевом токе во всём рассматриваемом интервале электрическое решение
пропускается. Нулевые R/потери в диагностике такого интервала означают
«не вычислялось», а не физический нулевой импеданс батареи.

Тепло ребра `I_edge² R_edge dt` делится между узлами по их половинам сопротивления.
Проверяются KCL, равенство входного и выходного тока и `ΣP_edge=I ΔV_ohmic`.
При заданном I пониженная проводимость может увеличивать общее тепло; в
параллельном пути ток и локальное тепло, напротив, уменьшаются. Несходимость,
разрыв цепи при ненулевом токе и выход R за заданные границы — ошибки, не
повод молча ограничить мощность.

Константный ток задаётся `electrical.current_a`,
либо используется `electrical.current_profile_a = [[seconds, amperes], ...]`.
Ток между точками линейный; интеграл его квадрата считается аналитически,
включая интервалы через несколько точек, смену знака тока и выключение источника.
Проводимости вычисляются по состоянию на начале подшага; обратная связь
ограничивается допустимым изменением температуры. Внутренние короткие замыкания
и обратимый энтропийный нагрев сюда пока не включены.

Это эффективное диссипативное сопротивление в режиме abuse, не измеренное
высокочастотное/омическое сопротивление конкретной ячейки. `U/I` также не является
внутренним сопротивлением: терминальное напряжение включает ЭДС и поляризацию.
`U I` не превращается целиком в тепло; неизрасходованная электрическая работа
не добавляется вторым термическим источником. Накопленный положительный заряд
`q+` нормируется на `Q_nom` для множителя R;
полный электрохимический баланс заряда/SOC ещё не объявляется откалиброванным.

**Ревизия 18.10.2026:** зарядка НЕ является R1 и не повреждает вещество.
Действующие уравнения и новые входные поля описаны в
[модели v6](model-revision-v6.md). Напряжение задаёт электрический бюджет,
а не скорость R1/выход φ. Дальнейший раздел сохранён как историческая запись
прежней калибровки, не как реализация новой химии.

Терминальное напряжение в прежней модели задавалось тем же электрическим логом, что и ток, и входило
только в выход B из R1 (`precursor_yield_voltage_per_v`), не как второй тепловой
источник. Зарядка образует тот же реагент отдельным каналом, не нагревая его
непосредственно при образовании:

`k_formation = k1_thermal(T) + k_charge`,
`k_charge = g * f_overcharge * max(I,0)/Q_nom`.

`g` — безразмерная интенсивность преобразования A в реагент B на один номинальный
заряд; Q_nom задаётся в кулонах. Зарядный источник не наследует Аррениус R1.
Без базового старения и ограничения работы после одного номинального заряда
остаётся доля A `exp(-g)`, а не `1-g`.
Интеграл положительного тока на подшаге
аналитический, в том числе при смене знака. Тепло выделяет R2, не R1. Для обычного
заряда/разряда `f_overcharge=0` по умолчанию: без модели SOC перезаряд не угадывается
по знаку тока. В этих опытах он явно известен из протокола: начальный SOC 100%,
затем заряд 35 А. Электрическое ускорение есть только у C2; C1/C3 электрически
отключены. Базовые параметры медленного старения R1 оставлены априорными — по
одному аварийному опыту их нельзя отдельно идентифицировать.
Ускорение R1 пока остаётся эффективным макрозаконом от полного тока ячейки;
новый электрический граф локализует Джоулев нагрев, но не подменяет этот закон
отдельной моделью электрохимических реакций на электродах.

При наличии записи напряжения на каждом зарядном подшаге проверяется
`Q_J <= ∫ I U dt - U_floor ∫ I dt`. `I U` интегрируется точно для обеих
кусочно-линейных записей, но **не добавляется** как второй источник тепла.
`reversible_voltage_floor_v` — явная априорная граница, не оценка OCV из U/I;
UPV использует 3.65 V. Нарушение отклоняет шаг (флаг 256), а не обрезает тепло.
Химическое накопление оплачивается из ПОЛНОЙ работы `∫ U I dt` после I²R:
`Q_J + E_charge_in <= ∫ U I dt`. Иначе вычли бы энергию ЭДС, которая как раз
запасается зарядкой. Неиспользованная работа не объявляется теплом.
Вся зарядная доля B оплачивается по явному приближению `q` Дж/кг;
`overcharge_formation_fraction` / `overcharge_pay` удалены, старые входы отвергаются.
Общий запас B хранит дополнительную энергию `precursor_charge_energy_j`.
Она учитывается в R2/R3 и химическом балансе с внешним источником
`electrical_chemical_input_j`. Тепловая деградация переносит исходную энергию
из A в B без электрической оплаты. См. [полный баланс](reaction-chain.md).

Кандидаты также ограничиваются начальным напряжением.
Для него используется явно неизмеренная консервативная нижняя оценка
обратимого напряжения 3.65 В, с допуском 50 мВ. Это ограничитель явно невозможного
I*R, а не замена будущей электрохимической модели OCV/SOC.

Новый протокол `scripts/calibrate_upv_r123.py` не читает старые профили:

1. Явные C1/C2/C3 с 3³ внутренними объёмами, отдельными оболочками и химией.
2. Одна траектория с начала нагрева, без сброса реагентов и состояния газа при аварии.
3. На нагреве подбираются электрическое сопротивление, R1/R2, температурный
   коэффициент выхода газа и связи. Материальные C/k, размеры батарей/прокладок
   и распределение целой измеренной C между корпусом и содержимым фиксированы.
4. Затем подбираются аварийные параметры по опыту без охлаждения. Валидационный
   опыт с водяной плитой используется после фиксации модели, без подбора по нему.

В первичном архиве есть отдельный электрический CSV для опыта без охлаждения.
Ток берётся из него; электрическая работа U I используется только как верхняя
граница допустимого джоулева тепла. Часы логгеров не синхронизированы: последняя
запись выключения тока совмещается с первой ступенью давления. Это **явная
неизмеренная предпосылка**, не доказанная синхронизация и не событие включения R2.
Для охлаждаемого опыта отдельной записи тока нет: берётся опубликованный ток
35 A до выхода терминального напряжения в compliance. Нет заданной температуры
C2 и нет температурного или временного включателя аварийной реакции.

## Аналитический баланс пакета

`scripts/analyze_upv_heat_balance.py` считает требуемый источник тепла без CUDA:
во внешнем балансе всего пакета внутренняя теплопроводность и неизвестные
контактные проводимости сокращаются, остаются измеренные теплоёмкости сцены,
измеренные температуры, боковые потери и измеренный ток. Неинструментированные
слои даны полосой (комнатная температура — максимум соседних датчиков), а не
одним интерполированным числом.

Для опыта без охлаждения до 866 с оценка источника составляет 62–95 кДж
(середина 84 кДж) при подведённой работе около 150 кДж. Это оценка по
поверхностным термопарам и допущениям о ненаблюдаемых слоях, не строгая
калориметрия. Постоянное R=24.5 мОм даёт около 25 кДж, но это **не** верхний
предел для переменного сопротивления. Точный интеграл I(U−3.65) ограничивает
электрическую диссипацию примерно 43.2 кДж; при нижнем обратимом напряжении
4.2 V — 27.1 кДж. Обе оценки условны на выбранный неизмеренный U_floor.
За первые 300 с оценка нагрева 7.3 кДж совместима с преимущественно I²R;
нельзя переносить этот вывод на весь предаварийный участок.

Ниже сохранена историческая диагностика старого ограничения R=24.5 мОм,
где остаток составлял ≥37 кДж. Это не новая калибровка Кирхгофа.
В модели тепло R2 и газ R2 — одно событие. При **постоянном** выходе
старые параметры были несовместимы с камерой: на умолчаниях
стадии heat 131 г превращённой массы дают 53 г газа → 11 489 бар в 5 см³
внутри C2; даже на самых благоприятных границах (`energy_j`=600 кДж,
`gas_fraction`=0.2, `gas_yield`=0.1) — 539 бар против потолка `shell_strength_pa`
в 100 бар. Измерения дают не более 2.2 г газа в камере до аварии (рост 3007 Па,
из них 1424 Па — тепловое расширение). CUDA-история с замороженным
`gas_yield_temperature=5e-4 /K` это подтверждает: кандидаты, закрывающие
температурную невязку, дают пик 4.8–6.2 бар против измеренных 1.06.

Закон выхода уже `y = min(y_max, y0 exp[bT (T−450 K)])`, но `bT` был забит
как `5e-4 /K` (5% на 100 K) и не входил в поиск. Это не расширение `y0` или
`energy_j`: при фиксированных умолчаниях стадии heat достаточно `bT ≈ 0.033 /K`,
то есть `E_eff = bT R T0² ≈ 55 кДж/моль` при 450 K, чтобы средневзвешенный выход
на прогреве упал до 0.016 и газ уложился в 2.2 г. Верхняя граница поиска
`0.08 /K` — 135 кДж/моль, обычный диапазон конденсированной кинетики, без
отрицательных наклонов. На аварии при 600 K выход упирается в `y_max=0.8`.

### Утечка шва снимает давление, но не газовый баланс

Механизм досрочного стравливания в модели уже есть: `deterministic_fraction`
открывает шов при `dp > seam_strength_factor·strength`, то есть впятеро раньше
матрицы (1.52 бар против прочности 7.59 бар при 368 K), и термическое ослабление
само по себе апертуры не создаёт. Щели сечением 0.028 мм² (диаметр 0.19 мм) хватает,
чтобы за последние 360 с прогрева пропустить весь газ, наблюдавшийся в камере.
Свободный объём пакета при этом не банк: при давлении срабатывания он удерживает
0.007 г, то есть практически весь образовавшийся газ обязан выйти.

Поэтому ограничением становится не давление, а газовый инвентарь: камера видела
не более 2.2 г, значит химия должна давать ≥27.4 МДж тепла на кг газа, тогда как
объявленные границы допускают максимум 24.0 МДж/кг (`energy_j`=600 кДж,
`gas_fraction`=0.2, `gas_yield`=0.1) — нехватка в 1.14 раза. Оценка 2.2 г сама
опирается на допущение, что средняя температура газа камеры следует за T109 (+2.2 K);
если газ камеры теплее, тепловое расширение объясняет больше измеренных 3007 Па,
допустимая стравленная масса падает, а нехватка растёт. Рост давления до аварии
гладкий и коррелирует с температурой C2, без ступеней, то есть данные дают только
верхнюю границу утечки, а не свидетельство срабатываний клапана. Корпус остаётся
`unidentified-pouch-laminate-PROXY`: наличие аварийного клапана — допущение, а не
спецификация источника.

Выходы отвергнутых кандидатов временные; сохраняются небольшие метрики и только
лучший сжатый прогон, чтобы не копить заново гигабайты расчётных трасс.

## Проверки Кирхгофа

`cuda_joule` проверяет аналитические последовательную и параллельную цепи,
геометрическую нормировку по трём осям, неоднородную сетку 8³,
конечную проводимость продуктов R1, сохранение тока/мощности, включение тока
внутри длинного шага, его разворот и точные интегралы I² и I U.
`cuda_transaction` проверяет также идемпотентность электрической диагностики.
Оба теста и `cuda_reaction_chain` прошли; CUDA memcheck на `cuda_joule` — 0 ошибок.

относительная невязка мощности 6.79e-16, тепловой баланс 5.21e-8 J.
Не более 6 итераций CG в сохранённых электрических снимках.

## Внешний резистивный нагреватель (2026-10-23)

Пассивный материал может иметь собственный электрический граф и выделять I²R:
это позволяет явно задать отдельную нагревательную плёнку в опыте FSRI.
Он не становится батареей, не включается в счётчик каскада и не может принимать
заряд или иметь зарядочную поляризацию. Используются прежние Кирхгоф, интегралы
I² и UI и неизменённая строгая проверка поступившей работы. Отдельного теплового
источника в обход электрического баланса или связности не добавлено.

Мощность плёнки в первом FSRI-прогоне — инженерное допущение, не опубликованный
лог источника. Поэтому внутреннее соблюдение UI не называется электрической
валидацией по измерениям. `cuda_joule` проверяет аналитический нагрев пассивного
резистора, отсутствие батарейных событий и запрет зарядочной химии.
