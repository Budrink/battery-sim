# Восстановление формы поправки по отношениям кривых

Работа только на сетке **3×3×3**. Подбор 4³/8³ остановлен. Здесь нет новой
подгонки квадратичного закона и нет изменения расчётного ядра.

Исходный расчёт: постоянная теплоёмкость батареи C = 412,87 Дж/К, исходная
анизотропная проводимость, без температурной поправки внутренних рёбер.
Внешние контакты оставлены с ранее найденными параметрами. Пересчитанный
на CUDA исходный вариант воспроизводит сохранённые температуры.

## Что делили

Для каждого канала:

```
R(t) = [Tэксп(t) − Tэксп(0)] / [Tрасч(t) − Tрасч(0)]
```

Это отношение нагрева, а не абсолютных температур: оно не меняется при переходе
от кельвинов к градусам Цельсия. Участки с нагревом менее 1 K хотя бы в одной
кривой исключены, чтобы не делить на практически нулевой сигнал. Начало анализа
не раньше 60 с. Порог 1 K — защитный численный выбор, не заявленная погрешность
термопар. Отдельно построена параметрическая кривая R(Tрасч).

На конце первого опыта получено:

| Грань | Нагрев эксперимента / нагрев расчёта |
|---|---:|
| C1 / ISS, горячая | 1,156 |
| C1 / TIM, холодная | 0,417 |
| C3 / TIM, горячая | 1,093 |
| C3 / ISS, холодная | 0,802 |

Это не одна общая поправка к температуре. Горячая грань может быть недогрета
одновременно с перегревом холодной. Такой рисунок согласуется с избыточным
внутренним перемешиванием тепла, но сам по себе не доказывает его причину и не
исключает ошибок контактов, теплоёмкости или наблюдателя.

## Приближение к функции внутреннего переноса

Дополнительно взяли **отношение перепадов между гранями**:

```
F = (Tгор − Tхол)расч / (Tгор − Tхол)эксп
```

Если бы сквозной поток был одинаковым, а элемент представлялся безынерционным
сопротивлением, это было бы Gнужное/Gисходное. В нашем нестационарном графе
запасается тепло, потоки зависят от узловых температур, а термопары измеряют
реконструированные поверхности, не внутренние узлы. Поэтому здесь F — только
**условная форма поправки**, не восстановленный закон материала.

По первому опыту получились следующие узлы функции. Аргумент — средняя
**расчётная температура двух поверхностей**, не температура донора ребра:

| Средняя температура граней, °C | F для C1 | F для C3 |
|---|---:|---:|
| 30 | 0,674 | 0,763 |
| 35 | 0,697 | 0,875 |
| 40 | 0,709 | 0,918 |
| 45 | 0,681 | 0,822 |
| 50 | 0,627 | 0,738 |

Обе кривые немонотонны: в этой части диапазона растут примерно до 40 °C, затем
снижаются. Они сохранены раздельно, с кусочно-линейной интерполяцией и без
экстраполяции. Их нельзя автоматически усреднить и объявить универсальной
функцией G(T): наблюдатель, потоки и температурные аргументы ещё не согласованы.
Их также нельзя назвать C(T). Теплоёмкость входит в баланс C dT/dt = Pнетто;
отношение температур не даёт ни производной, ни неизвестного Pнетто.

Получен диагностический образец формы, который можно использовать для выбора
табличного внутреннего закона и последующей обратной задачи на полном солвере.
В движок он **не подставлен**, новые коэффициенты не объявлены откалиброванными.
Исходная неоднозначность между восстановлением G(T) и C(T) остаётся существенной.
Нумерация C1/C3 по-прежнему является прежней неподтверждённой гипотезой.
