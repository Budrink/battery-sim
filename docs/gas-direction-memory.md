# Газовая связность с инерцией

В `cuda_network / averaged` эвристическая память направления заменена
сосредоточенным балансом импульса каналов. Старые `strength` и
`relaxation_time_s` удалены: загрузчик отвергает их, не переинтерпретирует.
Это новая физическая модель, а не переименование прежних коэффициентов.

## Закон канала

Ориентация каждого канала задаётся от A к B. Его состояние — подписанный
массовый расход `q` (кг/с) и кинетическая энергия `K` (Дж). При замороженной
на окне плотности и геометрии:

```
I = L/A
I dq/dt = pA - pB - R q - B q |q|
K = L q² / (2 rho A)
```

`L` — явно заданная физическая длина инерционного участка (двойственного
канала), `A` — текущее открытое сечение. Масса газа не добавляется вторично:
K представляет движение уже учтённого газа. Плотность участка приближённо
равна среднему плотностей двух объёмов.

Вязкая часть `R = 8 pi mu L / (rho A²)` соответствует эквивалентному круглому
проходу. `mu` — динамическая вязкость псевдогаза, входное свойство материала,
не калибровочный коэффициент памяти. Пока она постоянна в пределах сценария.
Прежний сжимаемый расход через отверстие задаёт квадратичное сопротивление
`B_orifice = abs(dp) / q_steady²`; при нулевом перепаде берётся конечный предел.
Трение длины и местные потери отверстия рассматриваются как последовательные
сопротивления. При переносе старого эффективного Cd необходимо проверить,
не включал ли он уже эти потери: автоматического повторного фиттинга нет.

Линеаризованное физическое время релаксации:

```
tau = I / (R + 2 B abs(q))
```

Оно не входит в JSON. Расход не обязан обнуляться при dp=0 и может некоторое
время идти против небольшого обратного перепада за счёт накопленной инерции.

## Направление на развилке

Перед окном собираются направления входящих ПРИНЯТЫХ расходов, взвешенные
потоком импульса `q²/(rho A)`. Для исходящего направления `n` применяется
безразмерная потеря `k_turn = 2 (1 - dot(mean_incoming_direction, n))`.
Она даёт добавку `B_turn = k_turn / (2 rho A²)` к сопротивлению.
Прямой ход: 0, поворот на 90°: 2, разворот: 4. Встречные струи создают
потерю перемешивания, но не произвольное предпочтение оси. Без входящего
потока дополнительная потеря равна нулю.

Это **явное замыкание неупругого перенаправления при одинаковом характерном
модуле скорости**: потеря на единицу массы равна `|u n_in - u n_out|²/2`.
Оно физически мотивировано, но не является единственным точным законом
реальной развилки. Нет разрешённого поля скорости, турбулентности, формы
струи, ударных волн или гарантии точности сверхзвукового выброса. Стенки могут
принимать импульс; сохранение векторного импульса только газа не заявляется.
Поворотная связь A→B и B→A определяется разными входящими потоками, не их
средним. Отдельного подбора силы анизотропии нет.

## Интегратор и термобаланс

Обратный Эйлер решает скалярный квадратный закон аналитически. Он даёт
`q = G dp + history`, где history зависит от предыдущего расхода. Эти два
члена входят в прежнюю одновременную сетевую задачу давления. Замороженная
матрица остаётся SPD; история входит в правую часть. Picard/CG-итерации
алгебраические, дополнительных физических микрошагов нет.

После ограничений запасов K вычисляется по фактически принятому переносу,
а не по неограниченному предложению. Изменение K поровну списывается с
тепловой энергии концов канала; при торможении возвращается в неё. Это
симметричное распределение работы по двойственным объёмам — ещё одно
допущение грубой модели. Сжимаемость/плотность обновляются между окнами;
точное решение сжимаемых уравнений Эйлера этим не заявляется.

R3 и перенос энтальпии получают тот же энергетический дебет. Нельзя ещё раз
прибавлять «нагрев трением»: он уже содержится в возврате механической
энергии и консервативном энергетическом расчёте. Проверка энтропии
нереагирующего переноса и положительности запасов сохранена.

Полный баланс включает тепло + K + химический/фазовый запас + внешние
потоки/работу. `ProcessDiagnostics.gas_kinetic_j` и соответствующий ряд
в casing probe показывают K отдельно. При выключенной инерции формат
траектории probe остаётся прежним.

## Конфигурация

```json
{
  "transport": "split_local_equilibrium",
  "mass_backend": "cuda_network",
  "network_integrator": "averaged",
  "dynamic_viscosity_pa_s": 0.00002,
  "directional_memory": {"enabled": true}
}
```

В каждом `gas_network.channels` обязательны `flow_direction: [1,0,0]`
и положительный `inertial_length_m`. Значения выше — иллюстрация, не
измеренные свойства продуктов горения. Длина не выводится из визуализации
или числа ячеек. При уточнении сетки длины/площади должны описывать ту же
геометрию, без дублирования инерционных объёмов.

Режим пока требует явных объёмов и каналов. Скалярный `ambient`-обмен
отклоняется: у него нет направленного порта импульса и энергии движения.
Нельзя молча применять его к новому состоянию. Подключение внешней среды
требует отдельно согласованной граничной модели; конечный внешний резервуар
не эквивалентен бесконечной атмосфере. Ребро в `outside_domain` уже не
поддерживалось данным CUDA-адаптером. Старые сценарии с ambient работают
как прежде при выключенной инерции.

По умолчанию режим выключен. Калиброванные сценарии, R1/R2/R3, оболочки,
тепловые контакты и learned profiles не менялись. Они не считаются повторно
валидированными с включённой новой физикой.

## Состояние, проверка и код

Checkpoint нового режима — `gas-momentum-v3`: расходы, K, вязкость и
геометрический контракт каналов. Старый `gas-clocks-direction-v2` отвергается:
из безразмерной эвристики нельзя восстановить импульс. Выключенный режим
сохраняет `gas-clocks-v1`. Prepare/commit, retry и reset транзакционны.
Перенос истории при перестроении графа пока запрещён.

Память: 16 байт состояния и 16 кандидатной копии на ребро, 32 байта геометрии
на ребро, 32 байта gather на узел. Один CSR gather и операции O(E) в
существующем cooperative kernel; нет обмена с CPU в штатном окне.

- Закон: `native/core/include/battery_native/gas/transport/gas_direction_memory.hpp`.
- Геометрия/моментум: `native/core/src/gas/transport/gas_direction_memory.cuh`.
- Согласование давления/энергии: `averaged_gas.cuh`, `reactive_average_gas.cuh`.
- Тесты: `native/tests/gas/gas_direction_memory.cpp`.

Основание редуцированного баланса и границы применимости сетевых моделей:
[COMSOL Pipe Flow, momentum and continuity](https://doc.comsol.com/6.4/doc/com.comsol.help.pipe/pipe_ug_fluidflow.05.42.html).
Численные проверки и регрессия записываются в журнал модели отдельно от
экспериментальной валидации.
