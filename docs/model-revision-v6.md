# Ревизия модели: зарядка отдельно от R1, 18.10.2026

Это действующая схема. Старые численные калибровки служат только стартовыми
параметрами, не доказательством точности пересмотренной химии.

## Четыре состояния вещества, три реакции и зарядка

```text
          зарядка, с оплатой из UI
    A ───────────────────────────────► Bc
    │                                   │
    └──────── R1, без тепла ─────────────┘
                      │
                φ Bd + (1−φ) S

    Bc и Bd ── R2 ──► S + газ + тепло
    газ + кислород ── R3 ──► продукты + тепло
```

A — исходное здоровое вещество с собственным химическим запасом; Bc — здоровый зарядочный реагент;
Bd — побочный реагент деградации; S — общий конденсированный остаток.
`activated_kg = Bc + Bd`, `healthy_charged_kg = Bc`,
`reactant_kg = A`, `residue_kg = S`. Дополнительного газового вида нет.

R1 действует на **оба здоровых состояния**, не только A. Она медленна в холоде,
ускоряется по своему Аррениусу, не выделяет тепло/газ и не восстанавливается
при охлаждении. `φ(T)` определяет побочный выход Bd; зарядка эту долю НЕ использует.
Напряжение больше не ускоряет R1 и не меняет φ.

При замороженной температуре и коэффициенте зарядки c:

```text
dA/dt  = −(k1+c) A
dBc/dt = c A − (k1+k2) Bc
dBd/dt = φ k1 (A+Bc) − k2 Bd
dM_degraded/dt = k1 (A+Bc)
```

Масса остатка при R1 возрастает на `(1−φ) k1(A+Bc) dt`.
R2 расходует `k2(Bc+Bd) dt`: доля y превращается в газ, остальное в S.
`D = M_degraded / M_initial` накапливает **только R1**; доля R2 и механическое
раскрытие оболочки — отдельные величины. R2 может лишить объём вещества и
зарядной способности, но не записывается второй раз в D.

## Электричество и зарядная ёмкость

`H=A+Bc` — оставшееся здоровое вещество.
`Q_available=Q_nom H/M_initial`: деградация уменьшает максимальную зарядную
ёмкость, простое превращение A→Bc при зарядке — нет. Это доступная ёмкость,
не остаток незаполненного места. Bc/H — заполнение дополнительного реакционного
запаса, НЕ измеренный SOC электродов. A-only начальное состояние не означает
«батарея разряжена»: её исходная химическая энергия уже содержится в qA.

`c = charge_conversion_per_nominal_charge * charge_acceptance_fraction *
max(I,0) / Q_available` задаёт эффективную скорость образования Bc из A.
При отсутствии здорового вещества зарядное образование равно нулю; насыщение
по A встроено в уравнение. Это упрощённый зарядный канал, не модель электродов
или обратимого разряда. Текущий эксперимент не идентифицирует полный цикл SOC.

Относительная электропроводность смеси:

`κ = [A+Bc + η(Bd+S)] / M_initial`, `0<η<=1`.

Поэтому R1 повышает базовое сопротивление, а зарядка сама по себе его через D
не повышает. Независимый эффективный множитель R(T,Q) описывает диссипацию
при зарядке. С 23.10.2026 этот множитель зависит от локального
`Bc/(A+Bc)`, а не от всего интеграла прошедшего тока. Непринятая зарядка
его не увеличивает, расход Bc через R2 уменьшает зарядочный вклад.
Коэффициенты требуют новой калибровки; старые значения по q+/Q несовместимы.
Кирхгоф распределяет ток, локальный нагрев равен I²R. Газ/пустота
не остаются проводящим твёрдым веществом. Тепловые связи на η не умножаются.

## Энергетический учёт

Исходное вещество имеет внутренний запас `q(A+Bc+Bd)`.
Зарядка добавляет оплаченный запас `E_charge`; принято `q_charge=q` как явный
неизмеренный энергетический масштаб. Заряженное вещество несёт исходную
энергию вещества **и** электрическую добавку: это не повторный учёт UI.

Каждый подшаг сохраняет `Joule_heat + charge_work <= integral(U I dt)`.
По решению пользователя фиксированный неизмеренный резерв 3.65 В снят из
основной UPV-калибровки: `reversible_voltage_floor_v=0`. Это не утверждение
о нулевой ЭДС: зарядочный химпотенциал оплачивается явно. Опциональные
пробы с ненулевым резервом остаются отдельным исследованием чувствительности.
Химический баланс включает электрическую работу отдельным внешним источником.
R1 не превращает энергию в тепло: энергия ветви в S учитывается как химически
недоступная, включая электрическую добавку, если R1 испортил заряженное вещество.
R2 высвобождает внутреннюю и доступную электрическую энергии реагента: часть
становится локальным теплом, часть — топливным запасом газа для R3.
Чувствительная энергия газа переносится из вещества, не создаётся второй раз.

R3 имеет собственный Аррениус и ограничена запасами топлива **и кислорода**.
В закрытой батарее исходный кислород нулевой; снаружи — заданный запас воздуха.
После открытия канала кислород может попасть и внутрь: запрета «гореть только
снаружи» нет. Охлаждение подавляет R2/R3 кинетически, без жёсткого триггера;
оно не восстанавливает уже израсходованные вещества или повреждения.

## Численная схема и границы ревизии

`advance_material_inventory` интегрирует приведённую треугольную линейную
систему **точно при замороженных T,c**, включая равные и нулевые скорости.
`advance_conversion` отдельно закрывает тепло/газ R2. Изменение T,c между
шагами разрешает общий адаптивный интегратор; точность полной траектории
проверяется dt/2. Дополнительных циклов химических микрошагов нет.

Геометрии переноса и их законы не заменялись: тепловой поток идёт по
направленным связям состояния, газ — по отдельному графу давления, прорыв
оболочки меняет доступность каналов с прежним учётом работы разрушения.
Обновлены только согласованные верхние оценки локальных источников для шага.

Удалены активные поля `overcharge_conversion_per_charge`, `overcharge_fraction`,
`precursor_yield_voltage_per_v`, `precursor_voltage_ref_v`; старый JSON отклоняется.
Новые имена: `charge_conversion_per_nominal_charge`, `charge_acceptance_fraction`.
У калибровки `overcharge_gain` заменён на `charge_formation_gain`.
`migrate_upv_chemistry_profile.py` создаёт отдельный полный seed с происхождением,
проверяет неизменность материалов/геометрий, не подставляет DEFAULT и не
переносит старые RMSE. Удаляемый старый коэффициент напряжения обязан быть нулём.

## Проверки и калибровка

`material_chemistry`: 375 сочетаний k1,c,k2,φ, балансы, точное разбиение времени,
зарядка без дефектов, деградация заряженного вещества, ёмкость/проводимость,
R2 без ложного D, подавление холодом. `cuda_joule`, `cuda_reaction_chain`,
`cuda_transaction` проверяют также общие CUDA-балансы, кислород и инвариантность
к размеру блока/повторной подготовке транзакции.

Совместный подбор использует первый опыт, неизменные U/I и контакты.
Подбираются электрический нагрев, зарядное образование и R1/R2; оболочки и R3
пока фиксированы. Холодные prior R1/R2 `k1,k2(25 °C)<=1e-7 с^-1` — инженерное
ограничение масштаба опыта, не калибровка календарного старения.
Второй опыт только проверяет уже замороженные параметры. Частичные/отсечённые
пробы не становятся лучшими и не получают фиктивную полную RMSE.
